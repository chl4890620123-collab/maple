# Google Sheets → Maple 시세 입력 (선택적 GAS 연동)

Maple의 **기존 SQLite/MariaDB와 FastAPI API를 그대로 유지**하고, 스프레드시트를 수동 시세 입력 창으로 사용하는 부가 기능입니다. GAS 자체가 DB를 호스팅하지 않습니다.

## 연결 전제

- 실행 중인 Maple 백엔드에 **외부에서 접근 가능한 HTTPS 주소**가 있어야 합니다. **GitHub Pages만으로는 FastAPI가 실행되지 않습니다.** 로컬 주소/사설 IP는 GAS에서 접근할 수 없습니다.
- Maple 백엔드에 `ADMIN_TOKEN`을 **반드시 설정**하세요. 이를 설정하지 않으면 기존 API의 쓰기 권한 보호가 비활성화됩니다.
- 실제 토큰을 Git, 스프레드시트 셀, HTML, GitHub Actions 로그에 올리지 마세요.
- 이 연동은 **사용자가 명시적으로 체크한 가격만** 전송하며, 기존 DB 테이블이나 기록을 삭제하지 않습니다.

## 설치 (Google 계정에서 한 번)

1. 개인 Google 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. 저장소의 [Code.gs](./Code.gs) 전체를 바인딩된 스크립트의 `Code.gs`에 복사해 저장합니다.
3. Apps Script의 **프로젝트 설정 → 스크립트 속성**에 아래 값을 직접 등록합니다.
   - `MAPLE_API_BASE_URL`: 예시 `https://maple.example.com` (실제 Maple 서버의 HTTPS 주소)
   - `MAPLE_ADMIN_TOKEN`: Maple 서버의 `ADMIN_TOKEN`과 같은 값
4. 시트 새로고침 → **Maple 시세 → 입력 시트 준비**를 실행하고 접근 권한을 승인합니다.
5. `시세입력` 시트의 **아이템명(A)**, **가격(B)** 을 넣고 전송할 행만 **C 체크박스(TRUE)** 를 체크합니다.
6. **전송 미리보기**에서 선택 값을 확인한 후 **검증 후 시세 전송**을 누릅니다.

**시트의 아이템명은 Maple `/api/market-prices`가 반환하는 이름과 정확히 같아야 합니다.** 고정 상점 가격, 알 수 없는 아이템명, 중복 이름, 음수/소수는 전송하지 않습니다. 한 번에 최대 500개까지 처리합니다. 처음에는 테스트 서버와 테스트 데이터를 사용하세요.

## 데이터 흐름

```
Google Sheets (가격 입력/체크)
  → GAS: 형식·중복 검사
  → GET  /api/market-prices (카탈로그·고정가 사전 검사)
  → PATCH /api/market-prices/bulk (X-Admin-Token)
  → Maple DB (market_prices + market_price_history)
  → 기존 계산 화면 반영
```

- 사용자가 버튼을 누르기 전에는 **서버 데이터에 아무것도 쓰지 않습니다.**
- 항목 검사 실패 시 전송하지 않습니다. API의 일괄 작업 오류는 화면에 표시됩니다.
- 같은 체크 항목을 다시 전송하면 동일 가격이라도 **새 시세 이력**이 남습니다. 전송 완료 후 C 체크를 해제하세요.
- 복사한 Apps Script는 해당 Google 계정에서 실행합니다. **GitHub PR 병합만으로 Google Apps Script가 배포되거나 인증되는 것은 아닙니다.**

## 안전성

- Google 시트와 Apps Script 프로젝트는 신뢰할 수 있는 관리자만 편집하도록 공유 권한을 제한하세요.
- 관리자 토큰이 들어가는 외부 호출이므로 요청 주소는 반드시 신뢰할 수 있는 HTTPS 엔드포인트로 설정하세요.
- 기본적으로 시간 기반 트리거를 설치하지 않습니다. 반복 동기화를 원한다면 별도 테스트 후 관리자 승인하에 구성하세요.
- 기존 API는 인증 방식에 따라 `ADMIN_TOKEN` 미설정 상태에서 쓰기를 허용할 수 있으므로 **운영에선 설정 필수**입니다.
